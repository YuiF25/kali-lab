# Kali Lab

Home lab de cybersécurité pour apprendre le pentest avec Kali Linux
et la détection d'attaques côté défense.

## Objectifs

- Prendre en main Kali Linux et ses outils (nmap, Metasploit, hydra...)
- Documenter chaque attaque dans un write-up (reconnaissance, exploitation, impact, remédiation)
- Détecter ces attaques avec un SIEM (Wazuh)
- Développer un outil Python d'automatisation de reconnaissance

## Structure

- `lab-setup/` : architecture du lab et configuration des VM
- `writeups/` : compte-rendus d'attaques
- `tools/` : scripts Python
- `detection/` : règles et captures côté défense
